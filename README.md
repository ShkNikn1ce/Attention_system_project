# Система тестирования внимания пилотов по методике Шульте

Веб-приложение авиакомпании на Django 5.2: назначение проверки, прохождение таблиц Шульте, расчёт ЭР, ВР и ПУ, заключение о допуске, динамика и сводный отчёт.

Роли: пилот, авиационный психолог, администратор. Формулы прежние: ЭР = (T1+…+T5)/5, ВР = T1/ЭР, ПУ = T4/ЭР.

## Запуск

```
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed
python manage.py runserver
```

Откройте http://127.0.0.1:8000/

`seed` создаёт только персонал и нормы допуска. Список пилотов при этом пуст: пилот регистрируется сам на странице «Регистрация пилота».

| Роль | Как появляется | Логин | Пароль |
| --- | --- | --- | --- |
| Администратор | команда `seed` | admin | admin123 |
| Психолог | команда `seed` | psy | psy12345 |
| Пилот | регистрация на `/register/` | задаёт сам | задаёт сам |

После трёх неверных паролей логин блокируется до конца работы с этой базой. Счётчик сбрасывается успешным входом, если лимит ещё не исчерпан.

## Проверки

```
python manage.py test schulte
```

Каталог `attention_system` — предыдущая консольная реализация на стандартной библиотеке. Её тесты по-прежнему запускаются так:

```
python -m unittest discover -s tests -t .
```
